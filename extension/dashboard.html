JSON 格式要求

顶层须包含 schema_version、scope、students。课程、作业、测验、学生、题目和附件 ID 须精确对应；ID 与分数使用字符串。每题须包含源文件 SHA-256、分数、满分、评语和复核状态。规范位于 schema/grade-plan.schema.json，虚构样例位于 examples/demo.plan.json。不接受原始运行证据或未定义字段。
